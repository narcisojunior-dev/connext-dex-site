# Connext Dex: site público

Arquivos públicos do Connext Dex, uma Pokédex para Android e iOS, servidos pelo GitHub Pages em <https://narcisojunior-dev.github.io/connext-dex-site/>. Este repositório não tem código do app.

| Caminho | O quê |
|---|---|
| `privacidade/index.html` | Política de privacidade do app ([abrir](https://narcisojunior-dev.github.io/connext-dex-site/privacidade/)) |
| `index.html` | Leva para a política |
| `cries/<id>.m4a` | Gritos dos Pokémon em AAC, para o iOS, que não toca o `.ogg` da PokéAPI |

## App de fã não oficial
O Connext Dex é um app de fã, gratuito e não oficial. Ele não tem vínculo com a Nintendo, a Game Freak ou a The Pokémon Company, nem é patrocinado ou aprovado por elas. Pokémon e os nomes, imagens e sons dos Pokémon são marcas e propriedade dos seus respectivos donos.

## Créditos
Os gritos são cópias convertidas para `.m4a` dos arquivos `.ogg` da [PokéAPI](https://pokeapi.co) ([PokeAPI/cries](https://github.com/PokeAPI/cries)), um serviço público e gratuito mantido pela comunidade. A conversão é feita pelo script `scripts/convert-cries.ts` do repositório do app.
